# API の一覧

ITO にある API を、1 枚で見渡すための一覧です。送る内容と返る内容のくわしい形は [api.md](api.md) にあります。

- API を足したり変えたりしたら、同じコミットでこの一覧と `api.md` を直す。
- フロントからは、必ず相対パス（`/api/...`）で呼ぶ。
- 起動中は、実装されている API を http://localhost:8000/docs でも確かめられる（機械が読む形は http://localhost:8000/openapi.json ）。

最終更新: 2026-11-28

## 1. 実装済み（このブランチで動くもの）

| メソッド | パス | 何をするか | 呼ぶ側 | 実装 | 状態 |
|---|---|---|---|---|---|
| GET | `/api/health` | バックエンドが動いているかの確認 | 確認用（画面からは呼ばない） | `back/src/main.py` | 動く |
| POST | `/api/drawings` | 書いた「と」（線のデータ、画像、ユーザーネーム）を受け取って保存し、結果（くつしたとメッセージ）を返す | 書く画面の「確定」（`front/src/api/drawings.ts`） | `back/src/drawings.py`（結果は `back/src/judge`） | 動く。結果は分析が作る（AI ありで 3〜11 秒）。保存先は手元の代わり |
| POST | `/api/judge/full` | 分析だけ（AI あり）。保存しない | 確認・調整用（画面からは呼ばない） | `back/src/judge/router.py` | 動く |
| POST | `/api/judge/geometry` | 分析だけ（AI なし）。保存しない | 確認・調整用 | 同上 | 動く |
| GET | `/api/socks` | くつした 50 種の台帳 | くつした一覧の画面（予定）で使える | 同上 | 動く |
| GET | `/api/refs/to` | 「と」のお手本の点の並び | 演出などで使える | 同上 | 動く |
| GET・POST | `/api/dev/*` | 手書きで分析を試す確認ページ、調整用サンプルの保存 | 開発用（`DEV=1` のときだけ。ほかは 404） | 同上 | 動く |

くわしい形: [api.md の POST /api/drawings](api.md#post-apidrawings)

## 2. 分析について

分析（`back/src/judge`）は取り込み済みです。画面（フロント）は、これまでどおり `/api/drawings` だけを呼べば、分析の結果（くつしたとメッセージ）が返ります。`/api/judge/*` は、分析だけを確かめたいときに使う口で、画面から呼ぶ必要はありません。くわしい形は [api.md の「分析だけを試す API」](api.md#分析だけを試す-apiapijudge)。

## 3. バックエンドが Worker に頼む口（本番だけ。仮）

ブラウザからは呼びません。バックエンド（コンテナ）が、保存のために Worker へ送る通信です。環境変数 `ITO_STORE_URL` があるときだけ使います。Worker 側はまだ実装されていません。形はインフラの担当と合わせて決めます。

| メソッド | パス | 何をするか | 本文 | 呼ぶ側 |
|---|---|---|---|---|
| PUT | `<ITO_STORE_URL>/objects/<キー>` | R2 にファイルを置く | ファイルの中身 | `back/src/storage.py` |
| DELETE | `<ITO_STORE_URL>/objects/<キー>` | R2 から消す（無くても成功） | なし | `back/src/storage.py` |
| POST | `<ITO_STORE_URL>/db/query` | D1 で SQL を実行する | `{"sql": "…", "params": […]}` | `back/src/db.py` |

くわしい説明: [data.md の「本番での保存先の切り替え」](data.md)

## 4. まだないもの（作る予定、または決めること）

| 何のための API か | 使う画面 | 決めること |
|---|---|---|
| 保存した「と」の一覧を返す | いろんな「と」を見る | 公開してよい記録の選び方、画像を配る URL、ページ分け |
| 1 件の結果を取り直す | 結果の画面（再読み込みしても残す場合） | ID をアドレスに入れるか |
| くつしたの一覧を返す | くつした一覧 | `GET /api/socks`（実装済み）を使うか、静的なファイルにするか |
| ユーザーネームを変える | 書く画面の右上（あとで実装） | サーバーに持つか、ブラウザだけで持つか（いまはブラウザだけ） |
