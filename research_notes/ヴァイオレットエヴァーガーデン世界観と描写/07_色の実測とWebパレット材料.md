**実測の方法と誤差（必読）**

- 支配色: 長辺 200px に縮小 → CIELAB 空間で k-means（k=8、k-means++ 初期化、乱数種 0）→ 各クラスタの RGB 中央値を代表色とした。面積比は縮小後の画素比。
- 部位色: 元画像の矩形内画素の「中央値」「最頻色（8 階調刻みで最多の箱の平均）」「輝度の下位 5% / 上位 5% の平均」。矩形は目視で指定したので、輪郭線・隣の部位が混ざる。表の「信頼度」列（矩形内の標準偏差で機械判定）を必ず見ること。
- 誤差要因: (a) 画像は JPEG / WebP の再圧縮品で、色差信号が間引かれており、細い部位（リボン、瞳、ブローチ、インクの線）は周囲の色がにじむ。(b) TV 場面写真は 768×432 に縮小されている。(c) 設定画 PNG は 530×520 と小さく、瞳とブローチは数十画素しかない。(d) キービジュアルには受賞ロゴ・コピー文字・白フチが入っており、白や金のクラスタに混入している。(e) 予告サムネは上下の黒帯・文字帯を除いて解析した。(f) 放送・配信の本編映像そのものは計測していない（公式が選んだ静止画のみ）。同じ色でも ±3〜8/255 程度の揺れを見込むこと。

## 1. 公式ビジュアルと場面写真の支配色は実測で何色か（画像ごと・場面タイプごと）

### Takeaway
TV 本編の公式静止画 104 枚を画素で集計すると、無彩色（C*<6）が 31%、橙〜金茶が 23%、青が 17% で、紫は 0.6% しかない。作品名に反して画面の主役は「暗い茶〜墨」「生成り〜金茶」「空と海の青」で、すみれ色はキービジュアルの花びらや劇場版サイトの空など、限られた場所に置かれた差し色である。全画素の 72% が彩度 C*<20、明度の中央値は L*=40 と、全体に暗く低彩度である。

### Inferences
- 【推定】UI の地色に向くのは「橙・金茶の明部 #E6D0B0〜生成り」と「無彩色の明部 #E7EBEA」、文字色に向くのは「無彩色の暗部 #302F2E」「青の暗部 #243447」「金茶の暗部 #504230」。作品の画面の比率（暗 4 : 中 3 : 明 3、無彩色と茶が過半）をそのまま UI に写すと重くなるので、UI では明部を地、暗部を文字に割り当て、中間の彩色（#5487B3、#A08157、#6D9B60）は面積を小さく使うのが実測分布と整合する。
- 【推定】「すみれ色を主色にする」案は、作品の画面の実測分布とは一致しない（紫 0.6%）。紫を使うなら、TV キービジュアルの花びら（#C5B5FA 付近）や劇場版サイト（#888FCA、#D1D4ED）と同じく「淡く、面か差し色として」が作品側の使い方に近い。
- 【推定】場面タイプ別パレットは、アプリの画面状態（例: 入力待ち=郵便社の日常、解析中=夜、手紙の開封=夕景や海と空）に対応させる材料になる。ただし各群の最大クラスタはほぼ必ず暗い茶〜墨であり、明るい画面にする場合は 2 番目以降の色を主に使うことになる。

### Gaps
- 本編映像のフレームを等間隔に抜き出した統計ではない。公式が広報用に選んだ静止画なので、人物のアップと見栄えのする場面に偏っている可能性がある。
- 外伝・劇場版の本編場面写真は、公式サイトでは予告サムネ（文字帯つき）しか取れなかった。ニュースサイト（アニメ!アニメ!、ナタリー等）掲載の場面写真は今回取得していない（公式サイトだけで 169 枚取れたため）。
- 「すみれの花」そのものが大きく写った公式画像は取得範囲に無かった。紫の実測は TV キービジュアル 2 の花びらと、原作小説表紙の小サムネ（250×351）に限られる。

### Inferences
- 【推定】UI の「青」の基準は、光源依存のない設定画 #43586E（とその影 #2B3E51）に置くのが安全。キービジュアルの #464E61 や夕景の #232D46 は、同じ上着が環境光で動いた結果なので、明暗 2 配色の変種として使える（明るい配色の文字に #2B3E51、暗い配色の面に #232D46 など）。
- 【推定】髪の金は「金色」ではなく、肌色に近い淡いベージュ（#EAD0AF、彩度 58%・明度 80%）で、白地の上では文字にも部品にも使えない（対 #FFFEEC で約 1.5:1）。金のアクセントが欲しい場合は公式サイトの金（#B4832F、#B39159。第 4 節）を使う方が筋が通る。
- 【推定】ブローチの緑は場面で青緑（172°）から黄緑（134°）まで動く。UI では設定画〜劇場版 KV の #16605E〜#266550（160〜179°、深いエメラルド）を代表値とし、明部 #38A47A・#6AB4AB を暗い配色用に回すのが実測の範囲内。
- 【推定】瞳の「水色のハイライト」（#66DAF3、#4ABDDE）は作品の中で最も彩度の高い青で、フォーカスリングや選択状態のような「小さく光らせる」用途の候補になる。

### Gaps
- 設定画の瞳とブローチは画素数が少なすぎ、基準値として弱い。色彩設計の色見本（公式が展示・書籍で公開したもの）の数値は入手できていない。
- ブーツとトランクの茶は、場面写真では足元が写らないことが多く、設定画（#634545）と KV2 のトランク（#44332A）以外の光源別データが無い。

## 5. スタッフは色の意図について何を語っているか（短く。詳細は別担当）

### Takeaway
色彩設計の米田侑加は、シリーズで最も大切にしたのは「リアリティー」で、キャラクターを背景から浮かせず「背景に馴染む」色を目指したと述べている。暗い場面は現実の暗さに寄せると人物が見えなくなるので、撮影と連携して加減したという。

### Cited Findings
- 【スタッフ発言】米田侑加（色彩設計）: 仕事は作品世界に合うキャラクターや小物の色を考えること、および季節・天候・時間帯に合わせて色を変える「色変え」。色指定スタッフと分担し、全体の一貫性を管理する — [劇場版 公式 スタッフ舞台挨拶レポート](https://violet-evergarden.jp/special/greeting02/)
- 【スタッフ発言】米田: 一番大切にしているのは「リアリティー」。アニメではキャラクターを背景より浮き立たせる色を使うことが多いが、本シリーズでは「キャラクターがより背景に馴染み、本当にそこに存在しているかのようなリアルな色味」を目指した — [同上](https://violet-evergarden.jp/special/greeting02/)
- 【スタッフ発言】米田: 電気が普及していない時代なので現実の暗さに寄せると「暗過ぎてキャラクターが見えなくなって」しまう。1 色で塗ると暗所から明所へ出ても色が変わらないというジレンマがあり、撮影スタッフと連携して加減した — [同上](https://violet-evergarden.jp/special/greeting02/)
- 【スタッフ発言】米田: 劇場版の夕景から再会までの一連はカットごとに色変えを行い、夕景は暮れていく様子が分かるよう 5 段階の色を作った。月明かりは幻想的に青白くし過ぎず、「ずっしりとした重さ」が出るようにした — [同上](https://violet-evergarden.jp/special/greeting02/)

## 8. Web の地色・文字色・アクセント色の候補として、コントラスト基準を満たす組み合わせは何か

### Takeaway

- 破綻 1（低コントラスト）: 作品は人物を背景に馴染ませる方針なので、同じ画面内の色どうしは比が低い。夜の髪 on 夜空は 1.24:1、蝋燭の上着 on 背景は 1.14:1、戦闘場面の肌 on 背景は 1.23:1。設定画の固有色どうしでも、ブローチ #16605E on 上着 #43586E は 1.00:1（輝度が同じで、色相だけで見分けている）、髪 on 肌は 1.22:1。場面パレットの色を「その場面の背景色の上の文字色」として使うことはできない。
- 破綻 2（色かぶり）: 夕景と蝋燭の場面では紙が #B38D59・#AC8454 まで橙に寄り、封蝋は #6C322A、インクは #77573A になる。夕景の紙色 #B38D59 を地にすると白文字も黒文字も中途半端になり（白に対して 3.06:1、#17100A に対して 6.16:1）、状態色の赤・金・緑は全部が橙〜茶に吸われて区別できなくなる。色かぶりした値は「その色相のアクセント 1 色」としてだけ使い、紙・インク・封蝋の関係は光源の影響が無い値（スリーブ、設定画、キービジュアル）から採る。
- 破綻 3（明部の白飛びと彩度）: 快晴の空 #65CCFE、海 #4AD3FC、麦畑 #F7E80E、瞳のハイライト #66DAF3 は彩度が非常に高く、紙色の上で 3:1 に届かない。面積を大きくすると作品の他の 9 割（低彩度）と釣り合わない。
- 破綻 4（公式の金）: 公式サイト自身が #B4832F on #EFEED9（2.87:1）、#B39159 on #FFF（2.95:1）、#9A8A3C on #FFF（3.46:1）と、金の文字で AA を満たしていない。公式値だからといって文字色に流用できない。
- 補正の考え方 1: 固有色（設定画・スリーブ・キービジュアルの値）を基準にし、場面の実測は「変種の方向」を知るために使う。上着なら基準 #43586E、暗い変種 #2B3E51 / #232D46、明るい変種 #5D6F81 / #7B8EA3。
- 補正の考え方 2: 色相と彩度を保って明度だけ動かす。下の補正表は HSL の H・S を固定し、指定の地色に対して 4.5:1（または 3:1）を満たすまで L を動かした最小変更の値。金は #B4832F → #8A6524（対 #EFEED9）、藤青は #888FCA → #5B64B6、空の青は #5AAEF0 → #116EB8、花びらは #9E85EF → #724EE8 になる。暗い配色では逆に明るくする（赤 #C12727 → #DB4B4B、菫色 #7058A3 → #8773B3）。
- 補正の考え方 3: 明るい配色と暗い配色で同じ HEX を共有しない。上着の青 #43586E は紙の上で 5.5〜7.2:1 だが、暗い地の上では 1.5〜2.9:1 で使えない。逆に蝋燭の #FDC16A は暗地で 6.8〜13:1 だが紙の上では面にしか使えない。役割ごとに明暗 2 値を持つトークン構成が前提になる。
- 補正の考え方 4: 面どうしの差（紙と紙、夜と夜）は 1.1〜1.2:1 しかないので、境界は罫線（公式の金の三重線など）か影で示す。罫線が意味を持つ UI 部品の境界なら 3:1 が必要で、金の原値は紙の上で不足する（#AF7F2E まで暗くすると対 #EFEED9 で 3:1）。
- 補正の考え方 5: 状態色は色相に頼らず、明度差と形（アイコン、文言、線種）を併用する。P 型・D 型で保たれるのは明度差と青黄の軸なので、エラーは暗い赤（#8C3434、L* 約 33）、成功は明るめの青緑（#16605E より #427E84 や #51AD99 の方向）というように明度をずらすか、成功を青系に振る案がある。

### Inferences
- 【推定】骨格として成立しやすいのは 3 系統。(1) 封筒系: 地 #ECE5D5 / 面 #FEFAEE / 文字 #17100A または #2B3E51 / 主 #8C3434 / 副 #245D4A / 装飾 金。(2) 制服系: 地 #FFFEEC / 文字 #2B3E51 / 主 #43586E / 副 #A54A4B / 装飾 #CFCBC2 と金。(3) 劇場版系: 地 白 / 面 #D1D4ED / 文字 #292929 / 主 #524078 / 副 #5B64B6。いずれも 8-4 の表で本文 4.5:1 を満たす対だけで本文・ボタンを組める。どれを採るかは後工程の判断。
- 【推定】暗い配色は、茶系の夜（#16130F + 蝋燭 #FDC16A）と紺系の夜（#142739 + 花びら #C5B5FA）の 2 系統が実測にあり、前者は「手紙を書く夜」、後者は「星空・夜の花」に対応する。明るい配色を封筒系にするなら茶系の夜、制服系・劇場版系にするなら紺系の夜の方が色相のつながりが良い。
- 【推定】金は「文字にしない装飾色」と割り切るか、補正値（#8A6524〜#7D6339）を「文字用の金」として別トークンにするかの二択になる。原値のまま小さな文字に使う選択肢は、基準上は無い。
- 【推定】P 型・D 型への配慮を優先するなら、主アクセントを青（#43586E）、副アクセントを金または封蝋の暗赤にし、赤と緑を同じ明度で対にしない構成が最も安全。

### Gaps
- APCA（WCAG 3 草案の知覚コントラスト）での評価はしていない。WCAG 2.x の比だけである。
- T 型（3 型）色覚と、1 色覚、ロービジョンでの見え方は検討していない。
- 細い明朝体・手書き風書体を本文に使う場合、W3C は基準値以上のコントラストが要ることがあると注記しているが、書体ごとの検証はしていない。
- 補正値は HSL の明度だけを機械的に動かした結果で、見た目の彩度が上がりすぎるもの（#724EE8、#116EB8 など）がある。OKLCH などの知覚均等な空間で作り直す余地がある。
- 実機（スマホの有機 EL、sRGB 外の広色域表示）での見え方は未確認。
